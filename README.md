# Auto-oglasi allows users to:
- Browse available cars by different criteria (brand, model, price range, etc.)
- Post new car listings with detailed information (e.g., make, model, year, price)
- Edit or delete their car listings
- Contact sellers via a contact form
---
## Technologies:
- Java – Main programming language used for backend development
- JPA (Java Persistence API) – For handling database operations and object-relational mapping (ORM)
- Servlets – For handling HTTP requests and responses in the application
- HTML/CSS – For building the frontend interface
- Bootstrap – For responsive design and styling
- Maven - For project management and dependency management
